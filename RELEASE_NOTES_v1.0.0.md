# 🎉 Unipulso v1.0.0 - Primeira Release

> Gerador de Pulseiras Hospitalares para Windows

## 📦 Download

**Instalador Windows**: `Unipulso_Setup_v1.0.0.exe` (28.08 MB)

**SHA256**: `EE884C6C37C793D94E5459856F57996A6B164326443E67F17DCDC0A9F947B26F`

## ✨ Funcionalidades

- ✅ **Interface Gráfica Moderna** - Sistema de abas com ttkbootstrap
- ✅ **Impressão Zebra ZD230** - Impressão direta via protocolo ZPL
- ✅ **Importação CSV** - Processamento em lote de pacientes
- ✅ **Exportação Múltipla** - PNG e PDF de alta qualidade
- ✅ **QR Code Automático** - Geração baseada em dados do paciente
- ✅ **Editor de Layout** - Personalização visual drag & drop
- ✅ **Instalador Profissional** - Instalação completa com atalhos

## 💻 Requisitos do Sistema

- **SO**: Windows 10/11 (64-bit)
- **Espaço**: 100 MB
- **RAM**: 2 GB mínimo
- **Impressora** (opcional): Zebra ZD230

## 🚀 Instalação

1. Baixe `Unipulso_Setup_v1.0.0.exe`
2. Execute o instalador
3. Siga o assistente de instalação
4. Pronto! Encontre o Unipulso no Menu Iniciar
