## 🔧 Modificação Técnica

### Arquivo: `core/render.py`

**O que foi mudado:**

1. **Lines 65-72** - Labels Abreviados
   ```python
   fields = [
       ('Nasc', 'Data de nascimento'),
       ('Mãe', 'Nome da mãe'),
       ('Conv', 'Convênio'),
       ('Med', 'Médico responsável'),
       ('Sex', 'Sexo'),
       ('Adm', 'Data de admissão'),
       ('Hora', 'Hora de admissão')
   ]
   ```

2. **Lines 251-317** - Renderização em 3 Colunas
   ```python
   col_w = int((text_max_w - 2 * col_gap) / 3)
   col_index = 0
   for field in fields:
       if y + line_height > max_y:
           col_index += 1
           y = y_start
   ```

3. **Espaçamento Reduzido**
   ```python
   col_gap = cm_to_px(0.05)        # Gap: 50% menor
   line_spacing = cm_to_px(0.02)   # Linhas: 81% menor
   ```
